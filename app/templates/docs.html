Feature-Based Image Matching & Automatic Panorama Construction

CSCD608: Advanced Computer Vision (3 Credits) — Postgraduate Examination Reference System

📌 Project Mandate

Develop a classical computer vision pipeline capable of detecting corresponding features across overlapping photographic views, estimating the 2D projective homography matrix via RANSAC, and constructing a seamless panoramic composite without relying on black-box APIs (such as cv2.Stitcher_create) or pretrained deep neural networks.

This documentation provides a comprehensive, A-to-Z technical walkthrough of the computer vision mathematics, modular source code architecture, empirical benchmark results, interactive web application, and one-click cloud deployment pipelines.

4. Mathematical Foundations

A homography is a 2D projective transformation relating two photographic planes $I_1$ and $I_2$. Given corresponding points in homogeneous coordinates $\tilde{\mathbf{x}} = [x, y, 1]^T$ and $\tilde{\mathbf{x}}' = [x', y', 1]^T$:

[ x' ] [ h11 h12 h13 ] [ x ] [ y' ] ~ [ h21 h22 h23 ] [ y ] [ 1 ] [ h31 h32 h33 ] [ 1 ]

In Cartesian coordinates:

x' = (h11*x + h12*y + h13) / (h31*x + h32*y + h33) y' = (h21*x + h22*y + h23) / (h31*x + h32*y + h33)
💡 Degrees of Freedom & Direct Linear Transformation (DLT)

Because $H$ is defined up to scale, it has 8 degrees of freedom. Each point correspondence provides 2 independent equations. Thus, a minimal sample of 4 non-collinear point pairs is necessary and sufficient to solve for $H$ using Singular Value Decomposition (SVD).

5. Image Preprocessing & Normalization

Module: src/preprocessing.py. Ensures consistent scale, single-channel representation, and validated spatial overlap:

  • Aspect-Preserving Resize: Constrains maximum dimension to 1280 px to bound computational complexity while preserving geometric ratios.
  • Grayscale Conversion: Standard ITU-R BT.601 luma conversion: $Y = 0.299 R + 0.587 G + 0.114 B$.
  • Input Integrity Validation: Rejects corrupted files, non-3-channel matrices, and zero-byte buffers.

6. Feature Detection: SIFT vs. ORB

Module: src/features.py. Implements the factory pattern returning detector/descriptor instances:

SIFT (Scale-Invariant Feature Transform)

Constructs a continuous Gaussian scale space: $L(x, y, \sigma) = G(x, y, \sigma) * I(x, y)$. Difference-of-Gaussians (DoG) extrema are located across 3 scale layers per octave:

D(x, y, sigma) = (G(x, y, k*sigma) - G(x, y, sigma)) * I(x, y)

Unstable extrema and edge responses are eliminated using the 2D Hessian matrix eigenvalue ratio $\operatorname{Tr}(H)^2 / \operatorname{Det}(H) < (r+1)^2 / r$.

ORB (Oriented FAST)

Uses FAST-9 corner detection across an 8-level image pyramid with scale factor 1.2. Retains the top $N=1000$ points scored by Harris corner response.

7. Feature Description

  • SIFT (128-D Float32): Computes 8-bin gradient orientation histograms over a $4\times4$ grid of spatial subregions. Normalized to unit $L_2$ norm to provide illumination invariance.
  • ORB (256-Bit Binary): Computes canonical orientation from intensity centroid moments $\theta = \text{atan2}(m_{01}, m_{10})$. Evaluates 256 steered pairwise intensity tests $\tau(p; \mathbf{x}_i, \mathbf{y}_i)$.

8. Descriptor Matching & Verification

Module: src/matching.py.

  • SIFT Matching: Euclidean distance ($L_2$) with Lowe's second-nearest-neighbor ratio test: $d_1 < 0.75 \cdot d_2$. Rejects ambiguous correspondences in repetitive textures.
  • ORB Matching: Hamming distance via hardware bitwise XOR (`POPCNT`) with bidirectional cross-checking: $(i \to j) \land (j \to i)$.

9. Robust Outlier Rejection via RANSAC

Module: src/homography.py. RANSAC iteratively:

  1. Randomly draws $s = 4$ point correspondences.
  2. Solves candidate $H_{cand}$ via DLT.
  3. Measures transfer reprojection error: $e_i = \|\mathbf{x}'_i - \text{proj}(H_{cand}\mathbf{x}_i)\|_2$.
  4. Counts inliers where $e_i < 5.0\text{ px}$.
  5. Re-estimates final $H$ over all consensus inliers using least-squares SVD refinement.

10. Homography Matrix Diagnostics

The diagnostic engine diagnose_homography() inspects matrix properties before warping:

  • Determinant Check: Ensures $\det(H) \in [10^{-6}, 10^6]$ to prevent singular projections.
  • Condition Number: Flags ill-conditioned matrices where $\text{cond}(H) > 10^8$.
  • Corner Bounds Sanity: Forward-projects image corners to ensure coordinates remain within reasonable canvas boundaries.

11. Dynamic Canvas Geometry & Warping

Module: src/warping.py. Prevents clipping negative warped coordinates:

x_offset = max(0, -min(warped_corners_x)) y_offset = max(0, -min(warped_corners_y)) T = [ [1, 0, x_offset], [0, 1, y_offset], [0, 0, 1] ] H_adjusted = T * H

12. Multi-Image Panorama Stitching & Distance Blending

Module: src/stitching.py. Combines multiple images into a reference coordinate frame. In overlap zones, distance-transform weighted alpha blending eliminates seam artifacts:

I_blend(x, y) = (D1(x, y) / (D1(x,y) + D2(x,y))) * I1(x, y) + (D2(x, y) / (D1(x,y) + D2(x,y))) * I2(x, y)

13. 8-Metric Evaluation Framework

Module: src/evaluation.py. Computes metrics M1 through M8 across all experimental runs:

  • M1: Keypoint Count: Total detected interest points per view.
  • M2: Match Count: Initial filtered correspondences.
  • M3: RANSAC Inlier Count: Number of geometrically verified correspondences.
  • M4: Inlier Ratio: Ratio of inliers to good matches ($N_{inliers} / N_{matches}$).
  • M5: Execution Timing: Stage-wise profiling (detection, matching, RANSAC, total).
  • M6: Panorama Quality: Non-black pixel coverage ratio and Laplacian gradient sharpness.
  • M7: Mean Reprojection Error: Average pixel distance of inlier projections.
  • M8: Homography Success: Boolean status with failure root cause logging.

15. Failure Diagnostics Taxonomy (F1–F5)

Proactive exception mitigation prevents pipeline crashes:

  • F1: Insufficient Keypoints ($N < 4$): Textureless scene or excessive blur. Aborts matching gracefully.
  • F2: Low Overlap ($N_{matches} < 4$): Overlap $< 15\%$. Prevents rank-deficient DLT solver.
  • F3: Outlier Dominance ($> 95\%$): RANSAC fails to find consensus. Flags pair in failure log.
  • F4: Degenerate Collinear Homography: Keypoints lie on a 1D line. Determinant test flags degeneracy.
  • F5: 3D Depth Parallax: Camera translation in non-planar scenes causes local ghosting.
